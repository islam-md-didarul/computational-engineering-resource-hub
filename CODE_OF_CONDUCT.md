# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project a respectful, harassment-free experience for everyone, regardless of background, identity, experience, or viewpoint.

## Expected behavior

Be respectful, constructive, evidence-oriented, and considerate of different levels of technical experience. Focus criticism on ideas and contributions rather than people.

## Unacceptable behavior

Harassment, discriminatory language, personal attacks, deliberate disruption, publishing private information, and other conduct that would reasonably be considered inappropriate are not acceptable.

## Enforcement

Report conduct concerns privately to the repository owner. Maintainers may remove, edit, or reject contributions and may temporarily or permanently restrict participation when necessary.

This code is adapted from the Contributor Covenant, version 2.1.

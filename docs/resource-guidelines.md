# Resource Review Guidelines

## Accepted resource types

- Official software documentation
- Open textbooks and course notes
- University courses and lecture series
- Interactive tutorials
- Benchmark and verification collections
- Research workflow handbooks
- High-quality reference sites

## Review criteria

A resource should be relevant, technically credible, accessible, reasonably maintained, and useful beyond a single narrow assignment. Primary sources are preferred for software and algorithms.

## Categories

Use one of the existing categories unless a genuinely distinct collection has at least three strong resources:

- Programming & Tools
- Numerical Methods
- Mathematics
- Physics & Mechanics
- CFD & Fluid Mechanics
- FEA & Solid Mechanics
- HPC & Parallel Computing
- Data, ML & Scientific AI
- Optimization & Control
- Research Workflow

## Levels

- **Beginner:** minimal prerequisite knowledge; introduces fundamental concepts.
- **Intermediate:** expects programming, mathematics, or discipline fundamentals.
- **Advanced:** assumes substantial theory or implementation experience.

## Access field

Set `free` to `true` only when the primary learning content is available without payment. Use `false` for paid books, subscriptions, or mixed-access platforms.
